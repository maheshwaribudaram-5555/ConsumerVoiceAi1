AI-Assisted Consumer Grievance Drafting and Legal Mapping System
============================================================
Skilltimate Technologies - Internship Project

A five-step wizard that captures a consumer complaint, checks evidence, drafts a formal notice under the Consumer Protection Act and plans escalation.

HOW TO RUN
  Windows : double-click run.bat (first run installs Streamlit, needs internet once)
  Mac/Linux: sh run.sh
  Manual  : pip install -r requirements.txt  then  streamlit run app.py
Requires Python 3.9 or newer.

OPTIONAL: open 'AI settings' in the sidebar and paste a free Google Gemini key for richer AI answers.
The app works fully offline without a key.
